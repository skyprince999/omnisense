## [ How It Works](#how-it-works)

```
RTSP Stream → Scene Indexing (batch) → Event Detection → Webhook Alert → Your Action
```

Every alert includes:

- **Timestamp** - When the event occurred
- **Event type** - What was detected
- **Video clip** - Playable evidence
- **Confidence score** - How certain the detection is
